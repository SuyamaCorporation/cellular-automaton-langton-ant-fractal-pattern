# ラングトンのアリ セルオートマトン フラクタル軌跡アート

Langton's Antセルオートマトンをキャンバスでリアルタイム可視化。マルチアリ・複数カラーテーマに対応。

## 機能

- 速度1〜1000 steps/frameで調整可能なリアルタイムシミュレーション（60fps対応）
- グリッドサイズ50×50〜300×300、カラーテーマ4種（クラシック/ヒートマップ/グラジエント/ネオン）
- 2〜4匹のマルチアリモード（RL/LLRR/LRRL/RLR各ルール選択可能）
- 約10,000ステップ付近のハイウェイパターン自動検出・通知
- PNGエクスポート、設定のlocalStorage永続化
